# سياق — English for Work

موقع تدريبي ثابت، عربي RTL وإنجليزي LTR، يقدّم 6 مسارات و18 درسًا مهنيًا مكتملًا بمستوى B1–B2. كل درس يسير عبر 8 جولات تفاعلية: 3 جولات حوار، تمرينان لترتيب الكلمات، كتابة، استماع، وتحدث.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث. من مجلد المشروع:

```sh
npm test
npm run build
npm run serve -- 4173
```

افتح `http://127.0.0.1:4173/`. لا تفتح `index.html` مباشرة؛ خادم HTTP مطلوب للـ ES modules وواجهات المتصفح. لا توجد حزم تشغيل أو تطوير خارج Node.js.

`npm run build` يخرج الموقع الثابت في `dist/`. كل الروابط والأصول نسبية، لذلك يعمل الموقع ضمن مسار GitHub Pages الخاص بالمستودع. يختبر GitHub Actions المحتوى والمنطق وسياسات الأمان قبل النشر.

## التقدم والخصوصية

يُحفظ التقدم محليًا تحت `siyaq-progress-v2`. يحافظ التحقق على الإصدارات، ويهاجر الإصدار السابق عند وجوده، ويستبعد القيم غير المعروفة. توجد نسخة استرداد محدودة للسجل التالف إن سمحت إعدادات المتصفح بالكتابة. يمكن مسح التقدم من إعدادات التخزين المحلية للمتصفح.

تُقارن الكتابة بصيغ معروفة محددة في الدرس؛ لا يقدم الموقع تصحيحًا مفتوحًا أو بالذكاء الاصطناعي. ميزة تحويل الكلام إلى نص تعتمد على دعم المتصفح وإذنه؛ النص المتعرّف عليه محفوظ محليًا ضمن جلسة الدرس، ولا يُحفظ تسجيل صوتي أو تقييم احترافي للنطق.

## الاختبارات

`npm test` يشغّل اختبارات Node المدمجة للمحتوى، ومسار الإكمال، وترحيل/تنظيف التقدم، وسياسات منع حقن HTML. لم تُضف أي اعتماديات. استخدم متصفحًا حديثًا مع خادم محلي لاختبار الواجهة والصوت.
