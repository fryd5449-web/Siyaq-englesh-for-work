# UX contract

| State | Learner outcome |
|---|---|
| Home | Sees current progress, the next lesson, six paths, and review immediately. |
| Path | Sees three distinct lessons and their completion states. |
| Lesson | Reads the work situation, goal, practical rule, and a common correction before starting. |
| Dialogue | Answers three linked turns; an incorrect reply explains a better response and allows a retry. |
| Sentence order | Builds from tap-selectable words and sees a rule-based correction. |
| Writing | Receives feedback only when the input matches a stored model or known variant; unsupported phrasing is not called incorrect by an AI. |
| Listening | Replays browser speech, answers for meaning, or opens a text fallback that is explicitly unassessed. |
| Speaking | Starts recognition only after a tap. Supported browsers can show a transcript and word differences; denied, failed, unsupported, or still-open capture can continue without a speaking score. |
| Completion | A lesson is counted only after all eight authored rounds are recorded and the learner chooses to finish. |
| Review | Shows missed answers, their corrections and reasons; resolved entries can be removed. |
| Persistence | Progress is schema-checked in local storage; unsupported records are filtered, v1 migrates, and corrupt data does not prevent learning. |
